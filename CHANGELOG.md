# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-09

### Added
- Initial release of Retail Product Recommendation System
- User-based collaborative filtering algorithm
- Matrix Factorization (SVD) implementation
- Ensemble recommendation method
- Comprehensive README with examples
- Unit tests for core functionality
- Sample retail dataset (retail_data.xlsx)
- Contributing guidelines
- MIT License

### Features
- Load and preprocess retail customer-product rating data
- Generate recommendations using multiple algorithms
- Calculate user similarity metrics
- Support for customizable recommendation parameters
- Performance considerations for scalability

### Known Issues
- Cold-start problem for new users
- Scalability limitations for millions of users
